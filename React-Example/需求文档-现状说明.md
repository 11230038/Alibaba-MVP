# React-Example 现状需求文档

> 文档类型：现状文档
>
> 适用读者：测试、管理层
>
> 范围：仅覆盖当前 `React-Example` 前端代码，不包含真实后端实现

## 1. 文档目的

本文档用于说明当前前端项目已经实现的页面能力、主要交互流程、模拟数据行为和验收观察点，方便测试同学按功能核对，也方便管理层快速了解当前版本的产品形态。

## 2. 产品概述

当前项目是一个面向阿里国际站卖家场景的前端演示应用，核心目标是把以下信息集中在一个运营工作台中：

- 客户聊天会话
- 客户画像与分析
- 业务卡片资产
- 系统状态监控
- Agent 配置与测试

当前版本以 **Mock 数据 + 前端交互** 为主，重点展示业务流程和页面结构，不连接真实生产系统。

## 3. 当前版本能力总览

### 3.1 页面结构

应用目前包含 5 个主页面：

1. **运营驾驶舱** `/`
2. **聊天工作台** `/chat`
3. **卡片池** `/card`
4. **系统状态** `/status`
5. **Agent 控制台** `/agent`

页面通过左侧导航进行切换；在移动端则通过抽屉菜单进入。

### 3.2 全局交互

- 支持账号登录态切换
- 支持侧边栏展开/收起
- 支持个人信息查看
- 支持账户切换
- 支持清除缓存数据的确认弹窗
- 支持登出后重新选择账号登录

## 4. 功能需求说明

## 4.1 账号与布局管理

### 4.1.1 账号登录

**功能说明**：
- 当用户登出后，系统进入账号选择页面。
- 用户可从多个卖家账户中选择一个重新登录。
- 登录成功后恢复到主工作台。

**当前实现行为**：
- 展示账号卡片列表
- 点击任意账户即可进入系统
- 登录成功后显示消息提示

**验收点**：
- 能看到至少一个可选账户
- 点击账户后能成功进入主界面
- 登录成功有明确提示

### 4.1.2 导航与页面切换

**功能说明**：
- 左侧导航提供 5 个页面入口。
- 顶部区域显示当前页面标题和简介。

**验收点**：
- 点击导航可进入对应页面
- 当前页面的标题和副标题与路由一致

### 4.1.3 个人信息与账户切换

**功能说明**：
- 用户可以查看当前账号详细资料。
- 用户可以切换到其他可用账户。

**当前实现行为**：
- 个人信息以弹窗展示
- 切换账户以列表方式展示可选项
- 切换成功后有消息提示

**验收点**：
- 个人信息弹窗可正常打开与关闭
- 账户切换后当前头像、名称和公司信息同步变化

### 4.1.4 清除缓存与登出

**功能说明**：
- 提供清除演示缓存数据的确认操作。
- 提供账户登出操作。

**当前实现行为**：
- 清除缓存为模拟动作，仅弹出确认和成功提示
- 登出后退出主工作台，返回登录选择页

**验收点**：
- 清除缓存需要二次确认
- 登出后必须回到账号选择界面

## 4.2 运营驾驶舱

### 4.2.1 页面目标

运营驾驶舱用于快速查看当前业务运行概况，包括：

- 客户会话状态
- 业务卡片沉淀情况
- Agent 可用能力
- 任务处理状态
- 客户潜力和运营动作入口

### 4.2.2 页面内容

当前驾驶舱包含以下区域：

1. **Hero 区域**
   - 展示产品定位
   - 提供进入聊天工作台和 Agent 控制台的快捷入口

2. **核心 KPI 区域**
   - 历史消息条数
   - 待处理未读数
   - 卡片资产数量
   - Agent 能力数量

3. **快捷动作区**
   - 聊天工作台
   - 卡片池
   - 系统状态
   - Agent 控制台

4. **趋势与摘要区**
   - 卡片捕获趋势图
   - 重点客户雷达
   - Agent 能力矩阵
   - 任务链路摘要
   - 卡片资产结构

### 4.2.3 当前实现行为

- 页面内数据来自 mock 数据计算
- 趋势图展示最近卡片捕获数量变化
- 快捷动作点击后跳转到对应页面
- Agent、任务、卡片信息会按轮播方式自动切换展示

### 4.2.4 验收点

- KPI 数值能正常渲染
- 快捷入口能跳转到正确页面
- 趋势图和摘要区可正常显示
- 页面自动轮播不影响基础浏览

## 4.3 聊天工作台

### 4.3.1 页面目标

聊天工作台用于模拟客户跟进的核心操作，包括：

- 浏览客户会话
- 查看消息内容和翻译
- 获取 AI 回复建议
- 分析客户意图和阶段
- 发送消息草稿
- 批量管理客户会话

### 4.3.2 会话列表

**功能说明**：
- 左侧展示客户会话列表
- 支持按更新时间分组
- 支持查看未读数和最近消息

**验收点**：
- 能切换不同客户会话
- 列表能体现未读状态、消息数和更新时间

### 4.3.3 聊天消息

**功能说明**：
- 显示当前会话的消息时间线
- 支持系统消息、卖家消息、买家消息和卡片消息
- 支持消息翻译展示
- 支持对买家消息重新翻译

**当前实现行为**：
- 翻译由 mock 数据和模拟服务返回
- 翻译开关可控制是否显示译文
- 重新翻译会更新当前消息的翻译文本

**验收点**：
- 消息时间线能正确显示日期分隔
- 不同消息类型展示方式不同
- 翻译按钮、重新翻译按钮可用

### 4.3.4 回复编排

**功能说明**：
- 用户可以输入卖家回复草稿
- 可通过智能助手生成建议
- 可发送消息或模拟发送

**当前实现行为**：
- 草稿框支持自动保存提示
- 智能助手下拉菜单包含 AI 建议、客户意图、客户阶段、翻译
- 发送前有确认弹窗
- 发送动作会把消息追加到消息列表

**验收点**：
- 不能发送空消息
- 输入后点击发送应新增一条卖家消息
- 智能助手操作可正常打开相应结果窗口

### 4.3.5 客户信息

**功能说明**：
- 展示当前客户身份、联系方式、行为、标签和可用性
- 支持基础和扩展两种客户信息视图

**验收点**：
- 客户切换后信息同步变化
- 身份、联系方式、行为统计、标签、可用性信息展示完整

### 4.3.6 批量管理

**功能说明**：
- 支持按更新时间或对话数对客户分组
- 支持选择、全选、反选、清空
- 支持导出聊天记录
- 支持群发消息的占位提示

**当前实现行为**：
- 导出功能生成本地 TXT 内容
- 群发消息当前仅为提示，不是真实发送

**验收点**：
- 批量选择可用
- 导出动作有结果反馈
- 群发消息有明确占位提示

## 4.4 卡片池

### 4.4.1 页面目标

卡片池用于统一展示和管理业务卡片资产，包括：

- 产品卡片
- 询盘卡片
- 通用业务卡片

### 4.4.2 页面内容

- 顶部支持按类型筛选
- 中间以卡片形式展示内容
- 底部支持分页浏览

### 4.4.3 当前实现行为

- 过滤条件包括：全部、产品卡片、询盘、其他通用卡
- 每页显示固定数量卡片
- 支持查看卡片捕获时间和详情

### 4.4.4 验收点

- 筛选条件切换后列表应更新
- 分页能正确跳转
- 不同类型卡片渲染样式正确

## 4.5 系统状态

### 4.5.1 页面目标

系统状态页用于展示当前模拟系统的运行健康情况，帮助测试和管理者快速判断链路状态。

### 4.5.2 页面内容

1. **运行健康度**
   - 用户状态
   - MITM 代理
   - MITM Receiver

2. **快捷测试动作**
   - 测试 ChatInput 操作
   - 测试 ContactSearch 操作

3. **任务队列**
   - 展示任务 ID
   - 展示操作类型
   - 展示目标对象
   - 展示任务状态和结果

### 4.5.3 当前实现行为

- 刷新状态会模拟更新最后检查时间
- Receiver 状态会在刷新时恢复为 online
- 新任务会经历 waiting、running、success 的生命周期
- 支持删除任务

### 4.5.4 验收点

- 状态卡片可正常刷新
- 快捷测试动作可生成任务
- 任务状态变化符合预期
- 删除任务会从列表移除

## 4.6 Agent 控制台

### 4.6.1 页面目标

Agent 控制台用于管理当前前端中展示的 LLM 配置、系统 Agent 和普通 Agent。

### 4.6.2 LLM 配置

**功能说明**：
- 展示全局 System Prompt
- 展示各 Level 的模型配置
- 支持编辑与重置

**当前实现行为**：
- 可编辑 Base URL、API Key、Model Name、Context、max_tool_rounds
- 全局 Prompt 可单独编辑
- 所有保存动作当前为模拟保存

**验收点**：
- 配置表格能正确显示各层级信息
- 编辑弹窗可保存修改
- 重置动作可恢复默认值

### 4.6.3 系统 Agent

**功能说明**：
- 展示系统内置 Agent
- 支持编辑名称、LLM Level 和 Prompt
- 支持重置默认配置

**验收点**：
- 列表展示正常
- 编辑后能保存
- 重置可恢复原始内容

### 4.6.4 普通 Agent

**功能说明**：
- 支持创建、编辑、删除普通 AgentPreset
- 支持配置工具授权
- 支持测试对话历史

**当前实现行为**：
- 可通过弹窗新建 Agent
- 可选择工具授权
- 可打开 Agent 测试台进行多轮测试
- 可复制、删除测试消息
- 可从历史消息某一轮分支出新测试对话

**验收点**：
- 新建、编辑、删除均有可见结果
- Agent 测试台能发送消息并生成模拟回复
- 历史分支、复制、删除操作可用

## 5. 数据与交互特征

当前前端的主要数据来源均为本地 mock：

- 客户会话数据
- 客户画像数据
- 业务卡片数据
- Agent 配置数据
- 系统状态数据
- 任务队列数据

### 5.1 模拟服务行为

当前模拟服务包括：

- 消息翻译
- AI 回复建议
- 客户意图分析
- 客户阶段分析
- 状态刷新
- 任务生命周期变化

这些行为均以延迟模拟真实请求，并用于展示交互效果。

## 6. 当前版本不包含的内容

以下能力在当前前端代码中尚未落成真实后端实现：

- 真实登录认证
- 真实 CRM 接口
- 真实消息发送
- 真实翻译服务
- 真实 Agent 调用
- 真实任务执行与状态回传
- 真实导出压缩包
- 真实缓存清除

## 7. 测试关注点

测试建议重点关注以下内容：

1. 页面切换是否正确
2. 登录/登出是否能回到账号选择页
3. 聊天页是否能正确切换客户
4. 翻译、建议、分析弹窗是否可打开
5. 发送消息后消息列表是否更新
6. 卡片筛选和分页是否正常
7. 状态刷新后状态和时间是否变化
8. Agent 编辑、重置、测试流程是否可用
9. 删除操作是否需要确认并且能正确移除数据

## 8. 验收标准

当以下条件满足时，可认为当前前端版本与现状需求一致：

- 5 个主页面都可正常访问
- 所有关键交互均有明确反馈
- 所有模拟动作都有结果提示
- 所有列表/弹窗/表格均能正常渲染
- 账号切换、消息发送、任务刷新、Agent 测试等核心流程可闭环演示

## 9. 总结

当前版本已经形成一个完整的阿里国际站卖家运营工作台前端原型：

- 以聊天工作台为核心
- 以卡片池和系统状态为辅助
- 以 Agent 控制台展示智能能力配置
- 以驾驶舱统一承接运营视图

整体上，它更像一个 **可演示、可测试的前端现状原型**，而不是生产级完整系统。
